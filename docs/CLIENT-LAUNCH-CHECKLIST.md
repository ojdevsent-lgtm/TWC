# TWC Client Launch Checklist

## Business
- [ ] Confirm legal entity/name and operating jurisdiction.
- [ ] Confirm regulatory/licensing position with qualified counsel.
- [ ] Replace sample testimonials with verified consented reviews.
- [ ] Confirm official support email, phone and social accounts.

## Product
- [ ] Confirm exact services offered.
- [ ] Confirm supported markets and jurisdictions.
- [ ] Define client onboarding and account lifecycle.
- [ ] Define human support escalation process.

## Integrations
- [ ] Select approved market-data provider.
- [ ] Select approved broker/trading provider if execution is offered.
- [ ] Select approved KYC/identity provider if required.
- [ ] Select payment provider if deposits/withdrawals are offered.
- [ ] Provision production OpenAI secret through a managed secret store.

## Security
- [ ] Separate development/staging/production secrets.
- [ ] Enable MFA for administrative users.
- [ ] Configure rate limiting and abuse monitoring.
- [ ] Verify HTTPS, security headers and restrictive CORS.
- [ ] Verify audit logging for privileged actions.
- [ ] Run dependency and secret scanning.

## Content
- [ ] Finalize Terms of Service.
- [ ] Finalize Privacy Notice.
- [ ] Finalize Risk Disclosure.
- [ ] Confirm cookie/analytics consent requirements.
- [ ] Finalize AI Assistant disclosure.

## Launch
- [ ] Connect production domain.
- [ ] Verify DNS and TLS.
- [ ] Test mobile, desktop and accessibility.
- [ ] Test contact/support flow.
- [ ] Test AI Assistant rate limits and escalation.
- [ ] Perform final client acceptance review.
